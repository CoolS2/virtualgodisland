# Соглашения по коду

## TypeScript
- Строгий режим из `tsconfig.base.json` (`strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`,
  `verbatimModuleSyntax`) — не ослаблять.
- Типы импортировать через `import type` / `type` в импорте.
- `any` запрещён; `as` — только с обоснованием (комментарий), `!` — когда инвариант очевиден из кода рядом.
- Предпочтительно функции + простые данные (интерфейсы), а не классы — особенно в `sim/` (сериализация).
- ES-модули, без default-экспортов (кроме конфигов инструментов).

## Стиль
- Отступ 2 пробела, LF, финальный перевод строки (`.editorconfig`). Одинарные кавычки, точки с запятой, trailing comma.
- Файлы — `camelCase.ts` / короткие существительные (`engine.ts`, `hand.ts`). Типы — `PascalCase`, константы — `UPPER_SNAKE`.
- Комментарии и JSDoc — на русском, кратко, объясняют «почему», а не «что».
- `TODO` только с номером этапа: `// TODO этап 2: ...`.
- Магические числа баланса — именованными константами в начале модуля (позже — отдельный `balance.ts`).

## sim/
- Чистые функции или функции, мутирующие только переданный `World`.
- Запрещено: `Math.random`, `Date`, `performance`, `setTimeout/setInterval`, DOM, `three`, `console.*`, I/O.
- Порядок итерации детерминирован (массивы, а не `Object.keys` объектов с числовыми/динамическими ключами).
- События для игрока — в `world.log` (позже — структурированные записи).

## client/
- Не содержит игровых правил — только отображение и ввод.
- Ресурсы three (геометрии, материалы, текстуры) освобождать через `dispose()` при удалении объектов.
- Ассеты — только с совместимой лицензией (CC0 и т.п.); источник и лицензию фиксировать в `docs/ASSETS.md` (создать при первом ассете).

## Тесты
- vitest, файлы `packages/<pkg>/test/*.test.ts`. Названия тестов — на русском, описывают поведение.
- Обязательные виды тестов для `sim/`:
  - детерминизм (одинаковый seed → одинаковый результат);
  - эквивалентность `catchUp` и живых тиков при изменении `step`;
  - баланс-гарды (например: человечек переживает сутки офлайна);
  - инварианты генерации (все биомы на 200 seed'ах).
- Тест бага: сначала воспроизвести (красный), потом исправить.
