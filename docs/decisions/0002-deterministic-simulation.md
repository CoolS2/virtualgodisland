# ADR-0002: Детерминированная симуляция с seeded RNG

- **Статус:** Принято
- **Дата:** 2026-11-04

## Контекст
Нужны офлайн-догонка (результат не должен зависеть от того, был игрок онлайн или нет), воспроизводимые острова
по seed и серверная проверка реплеем.

## Решение
- Внутри `sim` запрещены `Math.random()`, `Date.now()` и любое внешнее состояние.
- Случайность — mulberry32, состояние в `World.rngState` (`nextFloat(world)`); для генерации — `createRng(seed)`.
- Реальное время читается только в `catchUp(world, now)`.
- `World` — JSON-данные.

## Альтернативы
- `Math.random()` + сохранение результатов — нельзя проверить реплеем, офлайн ≠ онлайн.
- Сторонний PRNG-пакет — лишняя зависимость ради ~10 строк.

## Последствия
- Тест «`catchUp` ≡ N×`step`» обязателен при изменении тика.
- Числа с плавающей точкой: детерминизм гарантирован в пределах одного JS-движка; кросс-платформенность
  сервера (Node/V8) и клиентов (разные браузеры) для `Math.sin/cos/hypot` не проверена — проверить до этапа 6.
