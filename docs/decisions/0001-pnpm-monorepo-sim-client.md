# ADR-0001: Монорепо pnpm с отдельным пакетом симуляции

- **Статус:** Принято
- **Дата:** 2026-11-04

## Контекст
Логика мира должна работать в браузере (живая игра и офлайн-догонка) и позже на сервере (валидация реплеем, этап 6).

## Решение
Монорепо pnpm: `packages/sim` (логика, без рендера), `packages/client` (Vite + TypeScript + Three.js),
`packages/server` (NestJS, позже). `client` и `server` зависят от `sim`, обратная зависимость запрещена.

## Альтернативы
- Один пакет с логикой внутри клиента — нельзя переиспользовать на сервере, логика смешивается с рендером.
- Игровой движок (Unity/Godot) — тяжелее для браузера и для общего кода с Node-сервером.

## Последствия
- Логику можно тестировать без браузера (vitest).
- Нужно следить, чтобы в `sim` не проникали браузерные API.
