# ADR-0005: Переход на движок Godot 4 (GDScript)

- **Статус:** Принято
- **Дата:** 2026-11-04
- **Заменяет:** ADR-0001 (монорепо pnpm + Three.js), ADR-0003 (в части технологии; стиль сохраняется)

## Контекст
Three.js — только рендер: физику, анимации, редактор сцен, UI, звук пришлось бы собирать самим.
Владелец проекта выбрал готовый движок: надёжнее и меньше работы. Требование — бесплатно для коммерческого использования.

## Решение
- Движок **Godot 4** (лицензия MIT — без отчислений и ограничений по доходу).
- Язык **GDScript** (C# в Godot 4, по имеющимся данным, не экспортируется в Web — не проверено на актуальной версии).
- Точная версия Godot фиксируется при установке в `project.godot` / `CLAUDE.md` и меняется только через запись в CHANGELOG.
- Тесты — **GUT** (Godot Unit Test), версия пинится при установке, запуск headless.
- Принцип ADR-0002 сохраняется: логика мира (`sim/`) — детерминированные скрипты без сцены, рендера и реального времени.
- Цели сборки: Web (основная для плейтеста), позже Desktop/Android.
- Существующий TypeScript-код (`packages/`) — эталон для переноса; удаляется после того, как порт на GDScript
  повторит его поведение и тесты.

## Альтернативы
- Babylon.js — родной для веба, сохраняет общий TS-код с сервером, но редактор и инструменты слабее Godot.
- Unity — бесплатен только до порога дохода, условия лицензии менялись в одностороннем порядке.
- Unreal — нет экспорта в Web, 5% роялти.
- Остаться на Three.js — много собственной инфраструктуры.

## Последствия
- Общего TypeScript-кода с NestJS-сервером больше нет. План этапа 6 пересматривается: вероятный вариант —
  headless-Godot на сервере для валидации реплеем (решить отдельным ADR до этапа 6).
- Веб-сборка тяжелее (несколько МБ против ~0.5 МБ) — измерить на первой сборке.
- Доступны встроенные физика, анимации (импорт Mixamo/glTF), UI, звук, частицы.
- Детерминизм: собственный RNG (mulberry32) переносится; встроенные `randf()`/`randi()` в `sim/` запрещены.
  Физика Godot для логики мира не используется (не гарантирует детерминизм); она допустима только для визуала.
