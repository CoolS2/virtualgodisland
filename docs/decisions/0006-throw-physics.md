# ADR-0006: Физика броска — своя баллистика в sim/, траектория считается сразу

- **Статус:** Принято
- **Дата:** 2026-11-04

## Контекст
Этап 1: рука бога берёт и бросает предметы. Предметы — часть мира (сейв, офлайн, позже — кратеры, задания,
серверная проверка реплеем), поэтому результат броска должен быть детерминированным (ADR-0002).
Тик мира — 1 минута, а бросок длится секунды.

## Решение
- Полёт считает `Items.simulate` в `sim/`: гравитация, фиксированный шаг 1/60 с, затухающие отскоки,
  остановка на земле или падение в море. Высота земли — `IslandMap.height_at_world`.
- `Items.throw_item` сразу записывает в мир итог (точка падения или «утонул») и возвращает траекторию;
  `game/` только проигрывает её. Тик мира для этого не нужен.
- Физика Godot (Rigidbody, Jolt) для предметов мира не используется; допустима только для эффектов.
- Владелец проекта не выбрал вариант явно; решение принято по рекомендации и может быть пересмотрено
  (например, если броску не хватит «ощущения»).

## Альтернативы
- Физика Godot для предметов — реалистичные отскоки и катание, но недетерминированно и не воспроизводится
  реплеем; состояние зависело бы от частоты кадров.
- Мгновенное перемещение без полёта — нет ощущения броска, главной проверки этапа 1.

## Последствия
- Детерминированный, тестируемый бросок; сейв хранит только позиции.
- Нет катания по склонам и столкновений предметов друг с другом и с деревьями.
- Vector3 в Godot — float32: детерминизм в пределах одной сборки/платформы; кроссплатформенность проверить до этапа 6.
