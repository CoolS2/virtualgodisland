# ADR-0004: Модель времени — 1 тик = 1 минута, догонка до суток

- **Статус:** Принято
- **Дата:** 2026-11-04

## Контекст
Мир живёт, пока игрок офлайн (как Virtual Villagers), но отсутствие не должно убивать человечка и не должно
требовать долгих вычислений при входе.

## Решение
- `TICK_MS = 60_000`, `MAX_OFFLINE_TICKS = 1440` (сутки).
- `catchUp` прогоняет пропущенные тики тем же `step`; неполный тик переносится.
- Баланс-гард: за сутки офлайна человечек выживает (тест).

## Альтернативы
- Аналитическая формула офлайна — расходится с живой симуляцией, ломает детерминизм реплея.
- Без лимита — неделя отсутствия = 10 080 тиков и гарантированная смерть.

## Последствия
- Стоимость `step` ограничена: 1440 тиков должны считаться быстро (цель — < 100 мс, не измерено).
- Скорости потребностей временные, пересматриваются на этапе 2.
