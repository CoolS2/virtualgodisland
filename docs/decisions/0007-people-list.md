# ADR-0007: Несколько людей — `world["people"]`, семья и рождение

- **Статус:** Принято
- **Дата:** 2026-11-05

## Контекст
Этап 4.5 «Семья и поселение»: после тайны «Дом» приходит второй человек противоположного пола, появляются
пары и дети, поселение переживает основателя. Мир хранил одного человека (`world["human"]`).

## Решение
- Люди — массив `world["people"]` (порядок = порядок появления, детерминированно), у каждого `id`
  (`world["next_person_id"]`), а также `mother_id`, `father_id`, `partner_id`, `pregnant_until`.
- Знание еды — общее для племени: `world["knowledge"]` (дети и пришедшие учатся у остальных).
- Привязанность пар — `world["bonds"]`: ключ `"<меньший id>-<больший id>"` → 0..100.
- Приход второго человека: `world["newcomer_due"]` (тик прибытия, −1 — не ждём), выставляется постройкой дома.
- Логика семьи — `sim/family.gd`; поведение каждого — прежний `Human`, но функции принимают человека явно
  (`grab(w, h)`, `pet(w, h)`, `die(w, h, cause)` …).
- Игра окончена, когда не осталось живых людей (`WorldEngine.is_game_over`).
- Сейв v8: из v≤7 `human` становится `people[0]` (id 1), его `knows` — `knowledge`.

## Альтернативы
- Оставить `human` + массив «остальных» — две ветки кода везде, основатель особенный навсегда.
- Знание еды у каждого — пришедший без знаний умрёт рядом с едой; нужна механика обучения (позже можно).

## Последствия
- Все места, читавшие `world["human"]`, переходят на список; UI — выбор человека и список людей.
- Стоимость тика растёт линейно с населением; рост ограничен едой (фрукты растут медленно).
- Распределение работы по навыкам (кто добывает еду, кто лечит) — следующий шаг поверх списка.
