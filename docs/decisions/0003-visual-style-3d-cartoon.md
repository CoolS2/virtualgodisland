# ADR-0003: 3D мультяшный стиль на Three.js

- **Статус:** Заменено ADR-0005 (в части технологии; визуальный стиль в силе)
- **Дата:** 2026-11-04

## Контекст
Нужен узнаваемый стиль, достижимый одним разработчиком, с разрушаемым ландшафтом и рукой бога.

## Решение
3D, мультяшный low-poly (flatShading, цвет по биому), Three.js. Ассеты на старте — Quaternius / Kenney (CC0),
анимации — Mixamo. Подробности — `docs/GAME_DESIGN.md` → «Визуальный стиль».

## Альтернативы
- Пиксель-арт 2D — отвергнут: хуже передаёт руку бога, кратеры и свободную камеру.

## Последствия
- Размер бандла ~500 КБ из-за three — приемлемо.
- Лицензии ассетов нужно фиксировать (`docs/ASSETS.md`).
