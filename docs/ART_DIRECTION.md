# Арт-дирекшн: «тропический хэндмейд»

Один стиль для всего — острова, интерфейса, меню. Ощущение: тёплый остров, вещи сделаны руками
из дерева, верёвки, ракушек; пергамент со старыми записями. Спокойные природные цвета, без «кислоты».

Правило: насыщенность ниже, чем «по умолчанию в движке»; зелёные — с оливковым/жёлтым оттенком;
итоговый кадр дополнительно приглушён (`Environment.adjustment_saturation` ~0.9-1.05 по главам).

## Интерфейс
**Решение владельца (2026-11-05): элементы интерфейса — Kenney UI Pack Adventure + RPG Expansion** (CC0, `assets/ui/kenney`),
вместо прежних самодельных текстур.
- **Окна, меню** — кремовая панель в коричневой раме с металлическими уголками (`panel_brown_corners_a`).
- **Карточка человека, список поселения** — простая кремовая панель (`panel_brown`, вариант темы «Card»).
- **Верхняя панель и всплывающие сообщения** — тёмное дерево (`panel_brown_dark`).
- **Кнопки** — длинные коричневые (`buttonLong_brown`, нажатая — `_pressed`, неактивная — `buttonLong_grey`); наведение — светлее.
- **Логотип меню** — на красном баннере (`banner_hanging`). **Закрыть карточку** — `button_brown_close`.
- **Поле ввода** — вдавленная бежевая панель (`panelInset_beige`).
- **Полоски** — `progress_transparent_small` + `progress_white_small`, окрашенная приглушённым цветом смысла
  (сытость — охра, вода — голубой, силы — оливковый, вера — золото, любовь — пыльная роза, страх — лиловый).
- Тема собирается в `game/ui_style.gd` (`UiStyle.theme()`); каждый слой интерфейса начинается с `UiStyle.root()`.
  Нужен новый элемент — сначала искать в этих паках (архивы `assets/kenney_ui-pack-*.zip`), копировать в `assets/ui/kenney`.

## Шрифты
- **Lobster** — заголовки, имена, логотип на баннере (тёплый «рисованный», сочетается с Kenney UI).
- **Balsamiq Sans** — весь текст; **жирный** — кнопки и показатели на верхней панели.
- Оба с кириллицей, лицензия OFL (`docs/ASSETS.md`). Символы вне шрифта (звёзды, эмодзи) не использовать:
  в веб-сборке нет системных шрифтов на подмену — значки брать картинками из UI-паков.
- Заменили Amatic SC + Nunito (2026-11-05): с Kenney UI смотрелись чужеродно.

**Верхняя панель:** каждый показатель — в своём кремовом квадратике (`panel_brown`, вариант темы «Chip»),
значки из пака Adventure (кристалл — мана, звезда — вера).

## 3D
- **Ландшафт:** цвет — палитра в вершинах (`game/terrain.gd`), рисунок — текстуры ambientCG (трава, лесная
  подстилка, песок, камень) в `shaders/terrain.gdshader`: текстура делится на свой средний цвет, поэтому добавляет
  только деталь и не сдвигает палитру. Процедурные модели (`game/low_poly.gd`) остались только у облаков и брызг.
- **Стиль глав:** у каждой части острова своё настроение (`Daylight.MOODS`): берег — тёплый песок, земля предков —
  золотые закаты, тёмный лес — прохладная зелень (тёмная земля, тёмные деревья Nature Kit), вершина — чистый холодный
  свет. Рамка верхней панели по главам: дерево → камень → бронза → золото (`Hud.CHAPTER_FRAMES`).
- **Детали мира** (`game/details.gd`, Nature Kit, MultiMesh, ~8-10 тыс. штук, тени только у пней, брёвен и скал):
  цветочные поляны (кластеры 5-15; берег - жёлтые, земля предков - красные, тёмный лес - фиолетовые), грибы, пни,
  брёвна, камешки, кувшинки, папоротники, скальные уступы на склонах горы, травяные кочки. Правило «линий»: у реки и
  опушек детали гуще и выше, посреди полей редко - глаз цепляется за края. Тёмный лес - гуще подлесок, мох на
  деревьях и редкие бирюзовые светящиеся грибы. Не ближе 3 ед. к `map.relics`.
- **Свет:** низкое солнце утром и вечером теплее и ярче, на закате гуще дымка (обычный туман, высотный не
  используем - поддержка в Compatibility не проверена), у тёмного леса свет и туман холоднее.
- **Облака над закрытыми частями:** «море облаков» — три слоя (+3/+6,5/+10 над рельефом) с шейдером
  `shaders/cloud_veil.gdshader` (шум с прокруткой, внутри почти непрозрачные, к границе тают; нижний слой темнее).
  Оттенок по частям — `RegionVeil.COLORS`; при открытии части облака поднимаются и рассеиваются. Рука бога в них не
  заходит: упирается у края, отталкивается с дрожью и выпускает клубы облака (`Hand`).
- **Решение владельца (2026-11-05): финальная графика — готовые модели (вариант «В»), позже.**
  Требования к паку: единый стиль, мультяшный low-poly с гладким освещением, лицензия с коммерческим
  использованием (CC0 предпочтительно), glTF/GLB; человек — с риггингом и анимациями (ходьба, еда, сон и т.д.).
  Кандидаты: Kenney (Nature Kit и др.), Quaternius (Stylized Nature, Ultimate Animated Characters).
  Скачать из окружения разработки нельзя (Kenney блокирует автоматические загрузки, Quaternius — Google Drive):
  архив присылает владелец.
- **Сделано (2026-11-05):** природа, предметы и постройки — Kenney (палитра перекрашена, `tools/ui_art/recolor_kenney.py`),
  люди — Quaternius с анимациями (цвета кожи/волос/одежды задаются в `game/human_view.gd`), без головных уборов.
  Рука — модель владельца (`hand.glb`). Своими остались облака, алтарь, пещера, обелиск,
  обгоревшее дерево. Ландшафт — гладкое освещение без граней.
- При замене: сохранить природную палитру (пересветить/перекрасить материалы под таблицу выше), заменить
  функции `LowPoly.*` на загрузку сцен glTF; `sim/` не меняется.
- Меню показывает живой остров (сохранённый seed, иначе 42) в вечернем свете с медленным облётом.

## Направление игрока: тропы и ориентиры
- Тропы (`game/paths_view.gd`) ведут по маршрутам `Human.find_route`: старт (обломки) → обелиск → места берега и мост →
  руины → святилище и шахта → вершина. Полоса по рельефу с мягкими краями, цвет по части: земля `#c4ad7e` (берег, поле),
  камень `#a39a8c` (у руин и святилища), дерево `#80664a` (лес), серый склон `#9a9388` (гора).
- Деталь — плитки Nature Kit через MultiMesh: камни на земле, плитки и ряды колонн у руин, настил и брёвна в лесу.
- Ориентиры тянут взгляд дальше: указатели у развилок (обелиск, мост, руины), кострище у старта, колонны вдоль дорожки.
- Тропа обязана читаться сверху с высоты 60-150 ед.; света не добавляем.
