# Арт-дирекшн: «тропический хэндмейд»

Один стиль для всего — острова, интерфейса, меню. Ощущение: тёплый остров, вещи сделаны руками
из дерева, верёвки, ракушек; пергамент со старыми записями. Спокойные природные цвета, без «кислоты».

Правило: насыщенность ниже, чем «по умолчанию в движке»; зелёные — с оливковым/жёлтым оттенком;
итоговый кадр дополнительно приглушён (`Environment.adjustment_saturation = 0.9`).

## Интерфейс
- **Панели** — пергамент в деревянной раме с резным зигзагом, золотые ракушки по углам (`assets/ui/panel.png`).
- **Кнопки** — деревянные таблички с обмоткой верёвкой; наведение — светлее, нажатие — тёмное дерево.
- **Верхняя панель** — доска с волнами и золотыми точками по нижнему краю (тайлится).
- **Сообщения** — тёмная табличка с золотым кантом.
- **Разделители** — волна с бирюзовой точкой.
- **Полоски** — тёмный жёлоб и светлая заливка, окрашенная приглушённым цветом смысла
  (сытость — охра, вода — голубой, силы — оливковый, вера — золото, любовь — пыльная роза, страх — лиловый).
- Тема собирается в `game/ui_style.gd` (`UiStyle.theme()`); каждый слой интерфейса начинается с `UiStyle.root()`.
- Текстуры генерирует `tools/ui_art/generate_ui_art.py` (PIL, детерминированно) — менять стиль там, а не руками в PNG.

## Шрифты
- **Amatic SC Bold** — заголовки, логотип, имена (рукописный, «островной»).
- **Nunito** (+ лёгкое утолщение) — весь остальной текст.
- Оба с кириллицей, лицензия OFL (`docs/ASSETS.md`). Символы вне шрифта (звёзды, эмодзи) не использовать:
  в веб-сборке нет системных шрифтов на подмену.

## 3D
- **Сейчас (временно):** процедурные low-poly модели из кода (`game/low_poly.gd`), плоские грани,
  цвет в вершинах, без текстур. Это заглушки.
- **Решение владельца (2026-11-05): финальная графика — готовые модели (вариант «В»), позже.**
  Требования к паку: единый стиль, мультяшный low-poly с гладким освещением, лицензия с коммерческим
  использованием (CC0 предпочтительно), glTF/GLB; человек — с риггингом и анимациями (ходьба, еда, сон и т.д.).
  Кандидаты: Kenney (Nature Kit и др.), Quaternius (Stylized Nature, Ultimate Animated Characters).
  Скачать из окружения разработки нельзя (Kenney блокирует автоматические загрузки, Quaternius — Google Drive):
  архив присылает владелец.
- При замене: сохранить природную палитру (пересветить/перекрасить материалы под таблицу выше), заменить
  функции `LowPoly.*` на загрузку сцен glTF; `sim/` не меняется.
- Меню показывает живой остров (сохранённый seed, иначе 42) в вечернем свете с медленным облётом.
