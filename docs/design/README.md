# Спецификации задач

Пишет помощник `game-designer` (`.claude/agents/game-designer.md`), по файлу на задачу: `docs/design/<тема>.md`.
Спецификация — до кода: цепочка шагов, условия в терминах мира, подсказки и реплики, эффект, нужные тесты.
Принятые решения переносятся кратко в `docs/GAME_DESIGN.md`; файл спецификации остаётся как история «почему так».
